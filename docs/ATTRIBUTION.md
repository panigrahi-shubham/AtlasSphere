# EarthScope v2 data attribution

Country reference snapshot: https://github.com/mledoze/countries
Retrieved: 2026-10-26. The original records were reduced to English common/official
names, country codes, capital names, region/subregion, languages, country reference
coordinates, landlocked status and area. This derived database remains available
under the Open Database License (ODbL): see licenses/countries-LICENSE.txt.
The complete derived snapshot is included in src/data/countries.json.

World map/globe shapes: Natural Earth 1:110m via world-atlas, version locked in
package-lock.json. Natural Earth geometry is public-domain reference data;
world-atlas redistribution is ISC. Borders and names are simplified and may differ
from current claims. Map display expresses no political position.

Landmark summaries are original short editorial descriptions linked to UNESCO's
individual site records. Coordinates are approximate. No external site imagery,
photographs or map tiles are copied.

Weather: Open-Meteo model estimates. Location lookup: Open-Meteo geocoding based on
GeoNames. Internet is required for those requests. Check upstream terms for
commercial deployment, attribution and usage limits.
