# Planet encyclopedia sources and images

Scientific values use the [NASA/NSSDCA metric fact sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) dated 18 March 2025, checked 28 October 2026. Definitions are linked beside the data. Moon counts are explicitly dated snapshots; negative rotation indicates retrograde spin. Temperatures are mean reference values with different physical reference levels for rocky planets and giants, not forecasts. Each profile links its NASA Science source.

Images are used for non-commercial education under [NASA's media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). No NASA endorsement is implied. New assets are proportionally resized WebP encodings (maximum 1000 × 700 pixels), without compositing or AI alteration. Historical processing or enhanced colors are described in alt text. Credits are visible beside each image.

- Mercury: NASA / Johns Hopkins APL / Carnegie Institution of Washington. [MESSENGER image](https://science.nasa.gov/wp-content/uploads/2017/10/pia15051-mercury.jpg), `public/images/planets/mercury.webp`.
- Venus: NASA / JPL-Caltech. [Mariner 10 image](https://science.nasa.gov/wp-content/uploads/2024/03/venus-mariner-10-pia23791-fig2-16x9-1.jpg), `public/images/planets/venus.webp`.
- Mars: NASA / JPL-Caltech / MSSS. [Curiosity dune panorama](https://science.nasa.gov/wp-content/uploads/2017/11/pia17944.jpg), `public/images/planets/mars.webp`. This depicts terrain, not a full planetary disk.
- Jupiter: NASA / JPL / USGS. [PIA00343 Voyager image](https://www.jpl.nasa.gov/images/pia00343-jupiter/), `public/images/planets/jupiter.webp`. Captured 1979, processed 1990 with enhanced colors. The earlier unpublished Juno candidate is not used.
- Uranus: NASA / JPL-Caltech. [Voyager 2 image](https://science.nasa.gov/wp-content/uploads/2016/05/uranus-jpg.webp), `public/images/planets/uranus.webp`.
- Neptune: NASA / JPL-Caltech. [Voyager 2 image](https://science.nasa.gov/wp-content/uploads/2024/03/pia01492-neptune-full-disk-16x9-1.jpg), `public/images/planets/neptune.webp`. Historical enhanced blue processing is explicitly identified.
- Earth and Saturn reuse the existing credited assets documented in [Earth assets](archive/PHASE1_EARTH_ASSETS.md) and [science sources](archive/PHASE1_SCIENCE_SOURCES.md).

The profile's 3D link opens the same selected planet in the existing educational Solar System model. Its colors, geometry, orbital spacing and starting angles remain illustrative rather than a reconstruction of real-time positions.
